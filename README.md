# Gemini Agents

A collection of examples and implementations for Gemini-powered autonomous agents.

## Project Structure

- `src/agents/`: Core package containing the implementations.
- `tests/`: Project tests.

## Setup

1. Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install the package in editable mode with development dependencies:
   ```bash
   pip install -e ".[dev]"
   ```

## Development

- Run linting: `ruff check .`
- Run tests: `pytest`
